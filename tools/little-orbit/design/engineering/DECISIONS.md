## Distinctive proposal: Three-Reserve Priority Coupler

The idea to investigate is a mechanically readable **priority selector** driven by reserve position. All groups can supply the shared input; the groups are not each tied to one energy source. When timing reserve is below its refill threshold, the collection shaft winds the main weight/remontoire path. After timing reserve is sufficient, a separately clutched path charges the hydraulic lifted load for the next calendar/work burst. Only genuine surplus can drive the compressor/air demonstration. A freewheel/flywheel smooths input; it is not a fourth unlimited source.

Proposed implementation locus: child parts of **PW04** (selector/clutches), **RG02/RG03** (reserve-position request and isolated refill) and **HY06/AR04** (branch isolation). A weight-position lever/cam and gravity-biased latch are candidates. Hysteresis/dwell is required so the selector does not chatter between near-equal thresholds. Branches must disengage before a speed-incompatible coupling engages; no ideal torque router is hidden behind a gear picture. Relief/over-travel/backup functions remain separate from a priority decision.

This is an architecture hypothesis, not a dimensioned invention. E1 must define interfaces and failure states; E2/E3 must demonstrate reachable selector motion, torque isolation, recharge accounting, nonnegative losses and honest reserve exhaustion. If it proves more complex or less efficient than independent simple drives, simplify it and preserve the comparison in this log. The philosophical point survives: shared effort buys time for rest.
