## Runtime architecture to preserve

- Central immutable definitions select identities, style, roles, group mark and equipment; scenes never contain their own copies of a person. `engineering1` composes the existing `industrial` world recipe rather than creating a second industrial world.
- Separate mechanism/state math, energy accounting, story intent, actor contacts, SVG drawing and authoritative clock formatting. Use current project's browser-script and pure-Node patterns. File names above are proposals, not a demand for a rewrite or new framework.
- A frame includes one authoritative timestamp, civil reading, uniform elapsed phase/time basis, event/index state, reserve/story state, actor contacts and layout projection. Define seconds, minutes, hour and calendar carries once. Do not derive rates from frame count.
- Ordinary phases can reconstruct analytically from time. Any truly stateful energy study needs a documented initialization/reset, event stepping and deterministic accounting independent of render rate; it must not silently become persistent food/work history. Everyday qualitative gauges remain explicitly qualitative.
- After manual/DST/timezone changes, the civil display updates immediately and the illustrated model reconstructs. An autonomous physical model with uniform seconds cannot follow a 23/25-hour local day through an unchanging 24:1 gear ratio; use an explicit study basis or setting/correction event. Do not animate reverse clutches as if no correction were required.
- Keep cached mounted SVG, skip unchanged attributes, isolate detailed static art from moving layers, and use projected-size detail selection without deleting required contacts. A 60/400-state register does not need hundreds of animated text nodes.
- Any new script must be loaded/served/inlined in hosted, study and portable forms in the same order. Preserve license/attribution and no-network portable operation. Existing weather uses its current adapter; this theme creates no additional weather/time synchronization service.
- The default theme, existing browser overrides and six current themes remain. New user settings require a justified decision, documentation and fallback tests; do not expose simulator internals in ordinary clock settings.

## Independent acceptance matrix

| Area | Required evidence; what it can establish |
| --- | --- |
| Gear geometry | Independent tooth/module/center/phase fixtures, external-mesh speed sign, coaxial coupling and sampled noninterference; pitch-line relation `ω1*r1 = −ω2*r2`. Ratio-only tests do not prove proper tooth contact or manufacture. |
| Escapement and regulator | Full beat convention, locking/impulse/swing contacts, 30-tooth half-step arithmetic, fixed support and bounded driving disturbance. A sinusoidal drawn pendulum is not measured oscillator stability. |
| Calendar | Independent golden dates/carries for every month length and century cases; exhaustive 400-year sequence (146097 days, 97 leap years), year limits, program synchronization and exactly one midnight event. Expected values must not call the model under test. |
| Energy graph | Independent conservation examples, nonnegative stores/losses, finite exhaustion, charging attribution, incompatible-clutch isolation, input rest and air-loss backup. Validate SI versus normalized/qualitative models separately. |
| Object completeness | Every catalog/child ID, port/mate/support, hidden load path, source status and normal/isolated state is defined. No unexplained turning rotor, unsupported shaft or missing return line. |
| Worker anatomy | Painted palm/grip and heel/sole contacts, reachable joint envelopes, occupied-hand motion, safe phase-based release/rest; reuse/further calibrate the anatomy plan's independent gates. A hand merely near a rotating handle fails. |
| Face mark | Formula gives 1/2/3° adjacent offsets and 11/22/33° full spans; time-based phase, no wrong head/facing projection; native-size and quiet/LOD review. Group identity does not rely solely on tiny angular differences. |
| Readout and lifecycle | Complete device-current HH:MM:SS and date/year, 12/24 preference, no old/future mechanical digits competing, no 1 Hz live-region spam; quiet/hidden/Settings/rest/companions off/resume and abrupt jumps. |
| Layout and art | 854×480, 1280×720, 1920×1080, 390×844 × DPR1/2 × hosted/portable; full-screen machine, unobstructed controls/readout, character/prop bounds, color-independent path cues and motif readability. |
| Performance | Preserve all current tests and 66 cadence cases, original windows/warmups: low ≥26 updates/s and p95≤46 ms; normal ≥45 and p95≤31 ms; max gap<100 ms. Add actual rendered gear/palm/treadle/indexing motion in busiest mode, hydraulic/air state and all three people. No lowered gates or proxy-only counters. |
| Longevity/accuracy | Calendar math and browser cadence do not validate wear, synchronization, service or physical lifetime. Report physical performance only with its own data, uncertainty and conditions. |

No new application tests are run for this documentation-only session. Implementation results must include exact source/test revisions, portable checksum, passed/failed/unrun counts, visual motion review and remaining unknowns. Older Green House/desktop passes are not validation of this proposed theme; earlier intermittent rendering stalls remain unexplained.
